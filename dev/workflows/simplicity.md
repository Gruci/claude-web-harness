# 단순한 구현 선택

> 담는 것: 필요한 동작을 가장 작은 유지 가능한 변경으로 만드는 선택 순서. 담지 않는 것: 세부 관례(→ `../CONVENTIONS.md`). 읽는 시점: 구현 대안을 고르거나 과잉설계를 검토할 때.

첫 번째로 요구사항을 만족하는 선택에서 멈춘다.

1. 요청에 필요하지 않은 기능은 만들지 않는다.
2. 기존 프로젝트 헬퍼를 검색하고 재사용한다.
3. 표준 라이브러리를 우선한다.
4. 플랫폼의 기본 기능을 우선한다.
5. 새 의존성보다 설치된 의존성을 먼저 검토한다.
6. 가장 작고 명확한 구현을 쓴다.

읽기와 재현 및 데이터 무결성 검증을 생략하는 근거로 쓰지 않는다.
보안과 접근성 요구사항을 보존한다.
공통 경계를 수정하기 전에 모든 호출자를 추적한다.
의도적 지름길의 주석 규약은 `../CONVENTIONS.md`를 따른다.
