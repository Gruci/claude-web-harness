# design/CHARTS.md — 차트 패턴

> 담는 것: 어떤 데이터에 어떤 차트를 쓰는지, 계열색과 축의 결정 근거. 담지 않는 것: 래퍼 시그니처(정본은 코드)·일반 색상 의미(→ `design/COLORS.md`). 읽는 시점: 새 차트를 만들기 전.

아직 차트가 없다. 차트 라이브러리를 정하고 래퍼를 만들 때 이 문서를 채운다.

## 정해야 할 것 (첫 차트 작업 시)

- [ ] 차트 라이브러리 (참고: 원본은 Chart.js + react-chartjs-2)
- [ ] 래퍼 구조 — `frontend/src/charts/`에 타입별 래퍼(Line/Bar/Doughnut 등) + 공통 기본값(`CHART_DEFAULTS`) 자동 주입
- [ ] tooltip/legend 공통 스타일

## 규칙 (확정분)

- 모든 차트는 래퍼 경유 — raw 라이브러리 직생성 금지 (같은 타입 차트는 항상 같은 모양)
- 새 차트 타입 도입 시: 래퍼 추가 + 이 MD에 사용 패턴 기록을 같은 턴에
