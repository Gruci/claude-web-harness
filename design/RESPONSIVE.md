# design/RESPONSIVE.md — 반응형(웹+모바일) 정본

> 담는 것: 브레이크포인트, 데스크톱과 모바일 전환 방식, plan 반응형 설계표의 요구 형식. 담지 않는 것: 데스크톱 골격 자체(→ `design/LAYOUT.md`)·컴포넌트 내부(→ `design/COMPONENTS.md`). 읽는 시점: 화면 작업의 plan을 쓸 때, 그리고 폭이나 단위가 갈릴 때.

**원칙: 모든 화면은 설계(plan) 시점에 데스크톱·모바일 양쪽을 동등하게 정의한다.**
> 코드는 한 벌(반응형)이고 "모바일은 나중에 대응"은 금지 — 구현 후 모바일 대응은 리팩토링이지만, plan에서 두 배치를 함께 정하면 그냥 설계다 (파일 설계표와 같은 논리).

## 브레이크포인트 정본

| 이름 | 범위 | 대상 |
|------|------|------|
| mobile | < 768px | 스마트폰 (기본 검증 뷰포트 390px) |
| desktop | ≥ 768px | 태블릿 가로·노트북·모니터 |

- 중간 단계(태블릿 전용) 브레이크포인트는 실제 필요가 실증되기 전까지 추가 금지 (YAGNI).
- CSS 미디어 쿼리는 `@media (min-width: 768px)` 한 방향만 사용 — min/max 혼용 금지.
- 가능하면 브레이크포인트 없이 해결이 우선: `repeat(auto-fit, minmax(280px, 1fr))` · `flex-wrap` · `clamp()`.

## plan 반응형 설계표 (화면 작업 시 필수)

신규·수정 화면이 있는 plan.md에는 아래 표를 강제한다:

| 화면/컴포넌트 | 데스크톱 (≥768) | 모바일 (<768) | 전환 방식 |
|--------------|----------------|--------------|----------|
| (예) 요약 카드 4개 | 4열 | 2×2 | auto-fit minmax |
| (예) 실적 표 | 전체 컬럼 | 핵심 4컬럼 + 가로 스크롤 | 컬럼 숨김 + overflow-x |

## 강제 규칙

- **고정 px 폭 금지** — `width: NNNpx`(3자리 이상) 금지 → `max-width` + `%`/`minmax`/`clamp`. 불가피하면 `// px-ok: 사유` (static_check 게이트 14)
- **`100vw` 금지** — 세로 스크롤바 폭만큼 가로 오버플로 발생 → `100%` (게이트 14)
- **터치 타깃 최소 44×44px** — 버튼·탭·아이콘의 탭 영역. 시각 크기가 작아도 padding으로 확보
- **호버 전용 인터랙션 금지** — hover로만 접근 가능한 정보(툴팁·드롭다운)는 탭/클릭으로도 열려야 함 (터치 기기엔 hover가 없다)
- **표는 모바일 전략 필수 선택** — ① 핵심 컬럼만 남기고 가로 스크롤 ② 카드 리스트로 전환. plan 반응형 설계표에서 화면별로 지정
- **차트는 컨테이너 기반 크기** — 차트 래퍼(`frontend/src/charts/`, 첫 차트 작업 시 생성)가 컨테이너 리사이즈를 처리하고, 모바일에서 legend 하단 이동·축 틱 수 축소를 기본값으로 갖는다
- **완성 검증에 모바일 포함** — 화면 완료 선언 전 390px 폭에서 가로 스크롤 없음 + 주요 동작(필터·탭·터치) 확인. 데스크톱만 보고 완료 선언 금지
